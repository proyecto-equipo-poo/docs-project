# Docs Project - Documentación

## Descripción

Este repositorio contiene la documentación académica del proyecto de Programación Orientada a Objetos (POO) en Java.

Aquí se almacenan:

- Informes
- Evidencias
- Capturas de pantalla
- Explicaciones técnicas
- Manuales
- Documentación del desarrollo

---

## Contenido

- Informe del proyecto
- Evidencias de ejecución
- Capturas de GitHub
- Capturas del proyecto web
- Explicación del uso de Git y GitHub
- Organización del proyecto

---

## Herramientas utilizadas

- GitHub
- Git
- IntelliJ IDEA
- Java
- HTML5
- CSS3
- JavaScript

---

## Objetivo

Documentar todo el proceso de desarrollo, implementación y publicación del proyecto académico.
